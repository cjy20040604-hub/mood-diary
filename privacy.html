隐私政策与使用条款

生效日期：2026 年 10 月 15 日 · 版本 1

先说重点：你的心情和日记默认只保存在你自己的设备上，我们看不到。只有你主动开启云同步、服务器推送或 AI 复盘时，相关数据才会离开你的设备，并且每一项都会先单独征得你的同意。你可以随时导出或删除全部数据。晴一日记不是医疗服务。

1. 我们是谁

晴一日记是一个情绪记录与自我关怀的网页应用（以下称“本应用”），目前由个人开发者维护，处于原型阶段。联系方式：在 GitHub 仓库的 Issues 中留言。

2. 我们处理哪些信息

  • 你主动记录的内容：心情分数、情绪标签、触发因素、日记备注、想法整理内容、练习记录、昵称。
  • 设置信息：提醒时间与方式、主题偏好、是否已同意本政策及同意时间。
  • 仅在你开启对应功能时：
    • 云端账号与同步：你的邮箱、账号密码（由服务商以加密散列方式保存），以及在本机加密后的数据密文。
    • 服务器推送：浏览器生成的推送地址与密钥、提醒时间、时区。不包含任何日记内容。
    • GitHub Gist 同步：在本机加密后的数据密文，存放在你自己的 GitHub 账号中。
    • AI 复盘：本周的统计结果和部分日记文字，发送到你自己填写的 AI 服务。

我们不收集你的姓名、手机号、位置、通讯录，也不做广告追踪或用户画像。

3. 敏感个人信息

心情、情绪和日记内容可能反映你的身心健康状况，属于敏感个人信息。我们只为“帮你记录、回顾和照顾情绪”这一个目的处理它们。首次使用时，我们会请你单独同意；开启任何会把数据发出设备的功能前，会再请你单独同意一次。你可以随时撤回同意。

5. 我们不会做的事

  • 不出售、不出租、不共享你的个人信息。
  • 不读取你的日记内容（云端只有密文）。
  • 不在推送通知里放入任何日记内容。
  • 当你的记录中出现可能涉及自我伤害的内容时，不会把这些内容发送给 AI 服务。

6. 保存期限

  • 本机数据：保存在你的浏览器里，直到你删除或清除浏览器数据。
  • 云端数据：保存到你删除云端数据或删除账号为止。
  • 推送订阅：你关闭推送、删除全部数据，或浏览器推送地址失效时删除。
  • 为防止接口被滥用而记录的请求频率信息：只保存不可还原的 IP 摘要和计数，通常一天内自动清除。

7. 你的权利

  • 查阅与导出：在「设置 → 我的数据」导出 JSON 备份。
  • 更正：可以删除记录后重新记录。
  • 删除与撤回同意：在「设置 → 我的数据 → 删除我的全部数据」一次性删除本机数据、云端账号与数据、推送订阅；如使用过 Gist 同步，可一并删除或在 GitHub 手动删除。删除即视为撤回同意。
  • 单项撤回：取消勾选对应同意项、退出登录、关闭推送或断开 Gist，即可停止相应处理。
  • 如对个人信息处理有疑问或投诉，可通过第 1 节的方式联系我们。

8. 未成年人

未满 14 周岁的用户，请在父母或其他监护人同意并指导下使用本应用。如果监护人发现未成年人在未经同意的情况下使用，可以直接在设备上删除全部数据，或联系我们。

9. 安全措施

  • 本机加密与云端同步使用浏览器内置的 AES-GCM 加密，密钥由你的口令派生，我们不保存口令。
  • 云端数据表开启行级安全，每个账号只能读写自己的数据。
  • 推送等接口设有调用频率限制。
  • 没有任何安全措施能保证绝对安全。口令遗失后数据无法恢复，请妥善保管。

10. 不是医疗服务

本应用提供的记录、统计、周报、练习和 AI 复盘仅用于日常自我关怀，不构成医疗诊断、治疗或专业心理咨询建议，也不能替代专业帮助。统计结论基于你的记录，可能不准确。

如果你有伤害自己或他人的想法，请立即求助：全国心理援助热线 12356；希望 24 热线 400-161-9995；北京心理危机研究与干预中心 010-82951332。有立即危险时请拨打 120 或 110。号码如有调整，以官方公布为准。

11. 使用条款

  • 本应用免费提供，按“现状”提供，我们会尽力保证可用，但不保证不中断或没有错误。
  • 请勿利用本应用的接口进行批量调用、攻击或其他滥用行为。
  • 你对自己记录的内容拥有全部权利。
  • 因使用本应用产生的争议，适用中华人民共和国法律。

12. 政策更新

政策有实质变化时，我们会在应用内再次请你阅读并同意。旧版本的同意不会被用于新增的处理目的。
