安装到桌面 / 离线使用

安装后像 App 一样打开，断网也能记录。数据保存在本机。

我的档案与本机加密

不需要注册账号。设置口令后，本机保存的记录、同步令牌和 AI 密钥都会加密存储，每次打开需要输入口令。口令忘记后无法找回，本机数据只能清空，云端备份不受影响。

每日提醒

三种方式可以叠加：①应用内提示条；②服务器推送，关掉网页也能收到（需要允许通知，iPhone 需要先「添加到主屏幕」）；③写入手机日历的每日重复提醒。今天已经记录过，当天就不会再推送。

云端账号与同步

用邮箱注册账号，在多台设备间同步。数据先在本机用「云端加密口令」加密，服务器上只有密文，开发者和云服务商都读不到内容。忘记加密口令后数据无法恢复。

忘记云端加密口令？用恢复码重设
请保存你的恢复码

忘记云端加密口令时，只有它能找回云端数据。它只显示这一次，晴一不会保存。建议抄在纸上或存进密码管理器。

进阶：GitHub Gist 同步（可选）

用你自己的 GitHub 账号做存储：数据先在本机用口令加密，再存进一个私密 Gist。没有第三方服务器，没有人能读到内容。需要一个只勾选 gist 权限的个人访问令牌（GitHub → Settings → Developer settings → Personal access tokens）。

不想注册账号的话，也可以把加密数据存进你自己的 GitHub 私密 Gist。

AI 复盘（可选）

周报默认由本地规则生成，不上传任何数据。如果你有自己的大模型接口（OpenAI 兼容），可以填在这里，洞察页会出现「AI 个性化复盘」按钮。密钥只保存在本浏览器。
