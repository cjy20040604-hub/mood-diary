# 晴一日记说明书问答助手（RAG 练习）

用晴一日记的三份文档（隐私政策、README、AI 设计与评测说明）做知识库，回答用户关于这个产品的问题，每个结论都标注出处。资料里没有的问题直接拒答。

知识库文件 `index.json` 由 `ingest.mjs` 生成，没有放进仓库，运行一次就有。

## 运行
需要 Node.js 18 以上，以及阿里云百炼国际站的密钥。密钥只放在环境变量里，不写进文件。

```bash
export DASHSCOPE_API_KEY=你的密钥
node rag-demo/ingest.mjs                      # 建知识库：切块 + 向量化，文档更新后重跑
node rag-demo/ask.mjs "我的日记会上传吗？" --trace   # 提问，--trace 显示检索到的段落和相似度
node rag-demo/eval.mjs                        # 跑评测，结果写入 rag-demo/report.md
```

## 文件
| 文件 | 作用 |
|---|---|
| `lib.mjs` | 配置、调用 Embedding 和大模型、计算相似度、复用晴一日记的危机识别规则 |
| `ingest.mjs` | 读文档 → 切块 → 向量化 → 存成 `index.json` |
| `rag.mjs` | 问答工作流的五步 |
| `ask.mjs` | 命令行提问 |
| `eval-cases.json`、`eval.mjs`、`report.md` | 评测集、评测脚本、评测报告 |

## 工作流
| 步骤 | 做什么 | 为什么 |
|---|---|---|
| ① 安全检查 | 问题里有危机表达，直接给求助热线 | 和晴一日记一致，安全优先于回答 |
| ② 检索 | 问题转成向量，取最相似的 4 块 | 只给模型相关的资料，省 token，也减少干扰 |
| ③ 相关性门槛 | 最相似的一块低于 0.45，直接拒答 | 无关问题不调用大模型，省钱、更快、不会硬编 |
| ④ 生成 | 只根据这 4 块回答，每个结论标 [编号] | 让答案可以追溯，用户能核对 |
| ⑤ 校验出处 | 编号必须真实存在；没标出处的回答会被标记 | 不完全相信模型说的出处 |

## 关键参数
| 参数 | 取值 | 对应 Dify 里的配置 |
|---|---|---|
| 切块大小 | 约 400 字，按标题和列表项切，每块开头带“文档 › 章节” | 分段设置：最大分段长度、分段标识符 |
| Embedding 模型 | qwen3.7-text-embedding，1024 维 | 知识库的 Embedding 模型 |
| Top K | 4 | 召回设置：Top K |
| 相关性门槛 | 0.45 | 召回设置：Score 阈值 |
| 生成模型 | qwen-plus-character，温度 0 | LLM 节点的模型和参数 |

## 评测结果（20 条用例）
| 指标 | 结果 |
|---|---|
| 检索命中（答案需要的信息在前 4 块里） | 14/14 |
| 回答正确 | 14/14 |
| 该拒答的全部拒答 | 5/5 |
| 危机问题转求助 | 1/1 |
| 出处全部有效 | 14/14 |
| 延迟 p50 / p95 | 约 1.2 / 2.4 秒 |

## 这次学到的四件事
1. **切块决定检索质量。**第一版按句号切长段落，把列表项切成了半句话。改成先按列表项切、每块带上章节名之后，每块都是完整的一条信息。
2. **相似度衡量的是“话题像不像”，不是“有没有答案”。**天气、写诗这类无关问题，最高相似度只有 0.35 到 0.39，被门槛直接拦下。但“开发者毕业于哪所大学”的相似度高达 0.75，比一些能回答的问题还高，只能靠提示词里的拒答规则拦住。所以拒答要设计两层：门槛拦无关问题，模型拦“相关但资料里没有”的问题。
3. **评测器本身也会错。**有一题被判“答错”，其实是判分规则要求“2 条”带空格，而模型写的是“2条”。看到错误要先逐条核对，不能直接下结论。
4. **文档错了，答案就错。**搭建时发现 README 写的测试数量还是 86 项，实际已经是 87 项，助手会照着文档回答 86（已改正）。RAG 的上限是知识库的质量，文档维护本身就是产品工作。

## 局限与下一步
- 用例只有 20 条，而且是我自己写的；应该扩大，并留出一批不参与调参的题。
- 只用了向量检索。问题里有专有名词或数字时（比如“AES-GCM”“p95”），可以加关键词检索，做混合检索。
- 没有重排序（rerank）。资料多了以后，可以先取 20 块，再用重排序模型挑出最好的 4 块。
- 生成模型偏角色扮演，只因免费额度可用；正式使用应换通用模型，并重新评测。
